# Hospital Management System - GitHub Pages Version

This version is designed to run directly on GitHub Pages.

## Features
- Patient registration and login
- Doctor login
- Admin login
- Appointment booking
- Prescription management
- Payment record
- Doctor management
- Responsive Bootstrap interface

Patient: patient / patient123

## Important
This GitHub Pages version uses browser localStorage instead of PHP/MySQL. It is suitable for a college demonstration. It is not a production hospital system and does not provide real payment processing.

## GitHub Pages
Repository Settings -> Pages -> Deploy from branch -> main -> /(root) -> Save.
